# Podcast MP3 files

Replace the demo paths used by `podcasts.html` with the published episode files, or copy MP3 files here using these names:

- `episode-01.mp3`
- `episode-02.mp3`
- `episode-03.mp3`

The page uses native HTML5 `<audio controls>` with `type="audio/mpeg"`; no JavaScript player or external library is required.
